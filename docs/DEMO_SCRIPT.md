# 90-second demo script

1. **0–10 seconds — promise.** Open Bodh. “A child can bring an English maths doubt, but speak in Hindi or Hinglish. Bodh is not here to hand over an answer; it is here to find the missing idea.”
2. **10–25 seconds — listen.** Open *अपना सवाल समझें*. Enter `3/4 ÷ 1/8 = ?` and: “मुझे समझ नहीं आता कि इसे उल्टा करके multiply क्यों करते हैं।” Point out that the original notation and the learner’s own language stay visible.
3. **25–40 seconds — bounded diagnosis.** Show the readback, the linked fraction-division concepts, the evidence-backed tentative thought, and one small probe. “The model only chooses from this audited curriculum slice and cannot put an answer in this interface.”
4. **40–65 seconds — visual understanding.** Open the curated fraction lab. Answer the probe, choose a `1/8` tile, and place six tiles into the `3/4` target. “The learner sees the quantity before we name a rule.”
5. **65–82 seconds — transfer and return.** Solve the ribbon transfer, then return to the unchanged original question. “A new surface proves whether the idea moved, rather than whether the child copied the last screen.”
6. **82–90 seconds — trust.** Open the trace details or explain the 32-case evaluation corpus. “Raw learner work is not stored in the trace; safety failures fall back to the complete deterministic demo.”
